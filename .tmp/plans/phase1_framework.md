# 水体新污染物监测与风险研判平台 - 第一阶段设计规划

## 1. 目标与范围
建立平台的基础视觉规范、全局 CSS 变量、基础公共组件库，以及符合严格 1920×1080 尺寸的页面骨架。本阶段不涉及具体业务指标的实现，侧重于搭建可扩展且风格一致的“底座”。

## 2. 视觉与设计规范 (Design System)
在 `src/index.css` 中定义全局 CSS 变量，落实平台整体视觉要求。

### 2.1 颜色规范
- **背景与面板**
  - 页面背景: `#071522`
  - 面板背景: `#0D2235` (接近不透明)
  - 面板边框: `#24465F`
- **文字颜色**
  - 主文字: `#EAF3FA`
  - 辅助文字: `#A8BDCE`
- **状态与强调色**
  - 强调蓝 (Info/Primary): `#38BDF8`
  - 青绿 (Safe/Normal): `#2DD4BF`
  - 黄 (Warning): `#FACC15`
  - 橙 (Alert): `#FB923C`
  - 红 (Danger): `#F87171`
  - 未知灰 (Unknown/Null): `#94A3B8`

### 2.2 排版规范
- **字体**: 优先使用 Noto Sans SC / 思源黑体。
- **字号与行高**:
  - 主标题 (Header Title): 30-32px
  - 指标数字 (Metrics): 36-42px
  - 模块标题 (Panel Title): 20-22px
  - 正文 (Body): 18px
  - 辅助文字 (Caption): 16px (下限)
  - 溢出处理：不缩小字号，采用省略或减少条目。

### 2.3 效果与组件样式
- 禁止玻璃拟物化、复杂纹理、3D效果和发光阴影。
- 面板统一为 `8px` 圆角，`1px` 边框。

## 3. 布局框架 (Layout Framework)
画布固定为 `1920x1080`。为保证演示效果，根节点采用等比缩放容器（Scale-to-fit），避免因屏幕分辨率不同产生滚动条，内部像素严格匹配设计。

### 纵向空间分配（总计 1080px）
- 上外边距: `24px`
- 顶部标题栏: `64px`
- 间距: `16px`
- 导航栏: `40px` (含事件处置抽屉入口)
- 间距: `16px`
- 指标区: `104px`
- 间距: `16px`
- 主体内容区: `744px`
- 间距: `16px`
- 底部状态栏: `16px` (显示“演示环境｜模拟数据不用于监管决策”)
- 下外边距: `24px`

### 横向空间分配（总计 1920px）
- 左右外边距: 各 `24px`
- 主体列布局:
  - 左侧列: `360px`
  - 列间距: `16px`
  - 中间列 (含地图): `1120px`
  - 列间距: `16px`
  - 右侧列: `360px`

## 4. 基础公共组件库
在 `src/components` 下建立：
1. **ScaleWrapper**: `1920x1080` 等比缩放根容器组件。
2. **Panel**: 标准面板容器（带有背景色、边框及圆角规范）。
3. **StatusBadge**: 状态标签组件，支持配置不同语义状态色。
4. **Drawer**: 用于响应导航右侧“事件处置”点击的滑出抽屉组件容器。

## 5. 业务底线约束
- 代码层面落实：显示“未评价”(非安全)、区分“ND/缺测/0”、阈值标明“项目演示阈值”的底层逻辑和工具。
